## 统计边界

- 仅统计 Git 跟踪的文本源文件；
- 排除 `vendor/` 第三方依赖、`data/` 运行数据、`dist/` 发布产物及所有图片和视频；
- “物理行数”包含注释与空行，“非空行数”用于提供更保守的参照；
- Markdown 文档单独列示，不计入 86,758 行自研代码；
- 代码演进后应重新生成统计快照，不将旧数字冒充实时数据。
